# Security

jira-dash runs with your Jira API token and your `gh` login. It talks only to the Jira
site you configure, to GitHub through the `gh` CLI, and to commands you put in your own
keybindings.

If you find a vulnerability, report it through
[GitHub private vulnerability reporting](https://github.com/Ayyoub-Ka/jira-dash/security/advisories/new)
rather than a public issue. You will get a reply within a week.

Only the latest release is supported.
